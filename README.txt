THREADS CLOTHING CO. WEBSITE
==============================

Pages included:
- index.html — Home page
- shop.html — Product listing and filters layout
- new-in.html — New arrivals
- collections.html — Category collections
- about.html — About the brand
- contact.html — Contact form and FAQ
- product.html — Example product detail page

How to use:
1. Extract the ZIP file.
2. Keep the HTML files, styles.css, script.js and assets folder together.
3. Open index.html in a web browser.

The website is built with HTML and CSS, with a small JavaScript file for demo interactions (mobile menu, search filtering, cart count, and form messages).
Forms and cart are front-end demonstrations only; they are not connected to a payment system, database, or email service.
Product photos are cropped from the PDF supplied as the design reference.
